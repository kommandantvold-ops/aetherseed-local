# Reading texts

Source texts for `tools/reading_soak.py`, which reads a text to the unit one
passage at a time and reports how it responds. Build a shelf from a text with
`shelf_md.py`; `from_vpl.py` converts verse-per-line sources.

| File | Contents |
|---|---|
| `genesis.web.jsonl`, `song-of-songs.web.jsonl`, `luke.web.jsonl` | Public-domain (WEB) passages |
| `genesis-probes.json` | Questions for the Genesis passages |
